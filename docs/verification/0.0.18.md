On 22 October 2026, the shared release-preparation tool verified the published
release, source ancestry, full asset/checksum contract and DMG bytes. On an
Apple silicon Mac, the same bytes passed strict signature verification,
Gatekeeper's distribution assessment and stapled notarization validation.
Homebrew style, online cask audit and livecheck passed without exclusions.

The public command was then exercised on an Apple silicon Mac, using a private
Homebrew prefix and a task-owned app directory to protect the maintainer's daily
installation:

```sh
brew install --cask mr-streamer-oss/tap/mr-streamer
brew uninstall --cask mr-streamer-oss/tap/mr-streamer
```

Installation from public tap commit `c2b2f8aab61a4ee61e628ecaed9713ca5a70e849` passed. The installed bundle and packaged metadata both identify version
0.0.18 and bundle ID `app.mrstreamer.player`. The main bundle identifies the
published source commit above and passes its ASAR integrity check. The app's
deep strict signature and Gatekeeper execution assessment passed. The cask bytes
match the stable renderer's SHA-256
`61d588c899c3e626f9795055380f73a2e6cc77c47c0872ed05669fa15a35d99c`.

Normal uninstall passed, removing the app and Caskroom record. No test mount or
LaunchServices registration remains. Protected user profiles, shared Homebrew,
Keychain search/default configuration and daily app state stayed unchanged.
The test used an isolated non-default prefix, which Homebrew classifies as Tier
3; it did not modify the maintainer's shared `/opt/homebrew` installation.

Two verifier assertions were corrected after the one successful installation:
the test's app-directory environment value split at a space, and the app reads
its version from packaged metadata rather than a main-bundle string literal.
Both original failures remain in private evidence. No reinstall was needed,
and no app launch or native-flow pass is inferred from these package checks.

## Native verification limits

The app opened successfully in the maintainer's Wout account. Automated launch
of a prior test copy in the agent account remained suspended before Electron
started. That agent-account first-open, native Keychain retention, app-led
Squirrel update and ahead-version reconciliation remain unverified. The
maintainer explicitly directed publication with this disclosed gap. Signature
and packaging checks are not a claim that these native flows passed.

The source release's macOS packaged-app and analytics checks passed on its
GitHub runner. Other platform and installed-upgrade evidence is recorded in
[release run 406](https://github.com/Mr-Streamer-OSS/MrStreamer/actions/runs/39726182670).

No AUR publication is included. This is the project's own tap, not Homebrew's
main catalogue.
