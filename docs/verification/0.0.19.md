On the Apple silicon Mac mini, those exact bytes passed Homebrew 7.0.10 style,
online audit and stable livecheck without audit exclusions. A task-owned
Homebrew prefix, Caskroom, cache and app directory supplied the isolated local

metadata version directory identify 0.0.19. The app's bundle ID is
`app.mrstreamer.player`, its signing team is `UZ2SKVXJ4H`, and its integrity-checked
main bundle identifies the source above.

The DMG, ZIP and installed app have identical regular-file contents and symlink
targets. Strict signatures, Gatekeeper, hardened runtime and app/DMG stapled
tickets passed. The installed player passed fixture playback, bundled-tool lookup
and Privacy checks, including persisted opt-out, identity preservation and local
retry bodies. Automated app runs sent zero production analytics requests.

Normal uninstall removed the app and Caskroom record and retained all 65 files
of a UI-created disposable profile. The running-app guard refused replacement
until the owned app quit. No force, adopt or zap operation was used. The private
prefix is a Homebrew Tier 3 test environment; the maintainer's shared Homebrew,
daily app and profile were outside the test scope. Local recipe validation is
separate from verification of the fully qualified public install command.

## Native verification limits

Homebrew first-open, native Keychain retention, app-led Squirrel update and
Homebrew reconciliation when the app version is ahead remain unverified. The
maintainer explicitly accepted these four gaps for tested nightly
`0.0.19-nightly.20261023.416` at the source above and approved stable 0.0.19.
Direct executable launches used an explicit disposable profile and mock Keychain.
They do not establish those four flows. Physical AirPlay, audible output,
real providers and GPU behavior are not claimed.

The [stable release run](https://github.com/Mr-Streamer-OSS/MrStreamer/actions/runs/39973959335)
passed its package checks and Windows installed-upgrade gate. Broader acceptance
and public-route readback are recorded on the
[Release 0.0.19 card](https://github.com/orgs/Mr-Streamer-OSS/projects/1?pane=issue&itemId=280634965).

AUR remains held. This is the project's own tap, not Homebrew's main catalogue.
